# Project Mission

EAOIN is a production-quality voxel sandbox RPG designed as a long-term
software project.

## Core Goals

-   Production-ready architecture
-   Single-player and multiplayer
-   Procedural worlds
-   Modding support
-   Performance-conscious
-   Extensible for years of updates

## Core Principles

-   Maintainability
-   Modularity
-   Performance
-   Data-driven design
-   Stable public APIs
-   Clean architecture

## AI Development Rules

1.  Read the repository before coding.
2.  Read all documentation.
3.  Analyze existing systems before adding new ones.
4.  Implement the largest cohesive milestone possible.
5.  Keep the project compiling.
6.  Add tests where practical.
7.  Update documentation after implementation.
8.  Never rewrite working systems without a justified reason.
